# Модуль фитнес-трекера

Консольная программа на Go для обработки данных о тренировках и ежедневных прогулках.

Приложение разбирает записи с количеством шагов, длительностью активности и видом тренировки — бегом или ходьбой. С учётом роста и веса пользователя оно рассчитывает дистанцию, среднюю скорость и расход калорий, а затем выводит отчёт в консоль.

Учебная работа по основам Go: структуры, методы, эмбеддинг, интерфейсы и разделение кода на пакеты.

## Установка и запуск

1. Установите [Go](https://go.dev/dl/) версии 1.24.1 или новее. Проверьте установку командой `go version`.
2. Склонируйте репозиторий и перейдите в его каталог:

   ```bash
   git clone https://github.com/Feym4n/go-fitness-tracker.git
   cd go-fitness-tracker
   git switch first-iteration
   ```

3. Запустите приложение из корня проекта:

   ```bash
   go run ./cmd/tracker
   ```

Данные для примера заданы в `cmd/tracker/main.go`.
